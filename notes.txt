# Task: Complete the new microservice — endpoint alignment, bearer token validation, and MasterCard connectivity

## Goal
Finish the remaining work on the new microservice so it can be deployed to the dev environment, where I will verify that:
1. The endpoint rejects requests without a valid bearer token, the same way the other services in this project do.
2. The endpoint successfully connects to MasterCard. Any error MasterCard returns should be a request validation error (e.g. invalid payload), NOT an authentication or authorization error. Request correctness will be handled later.

## Context (already done, do not redo)
- The service is a Spring Boot 3.5.16 microservice. The skeleton runs cleanly locally and is deployed to dev.
- Local Vault token authentication is set up the same way as the other services (the token is copied from OpenShift for local runs).
- The new REST endpoint is implemented based on a Confluence spec. It currently returns a fixed response.
- The OpenAPI migration is done: a generated controller interface, generated request/response models, and a MapStruct mapper to the legacy request/response objects, following the same approach as the other services.
